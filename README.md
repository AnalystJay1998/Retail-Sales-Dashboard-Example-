# Product Sales by Region Dashboard

An interactive retail sales dashboard built from 1,500 orders (January 2023 to June 2025).

## What it shows
- Revenue, orders, average order value and return rate, with year-on-year comparison
- Monthly revenue trend
- Revenue by product, salesperson, promotion and payment method
- Region scorecard with manager, return rate and delivery time

## Filters
Year, region, product and customer type.

## Data
Source file: `Product-Sales-Region.xlsx` (orders, products, regions, discounts, returns, delivery dates). Revenue is the order total after discount and before shipping. The data has no cost or currency fields, so there is no margin view.
